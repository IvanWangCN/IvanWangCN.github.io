## 为什么要用 LLM 做分类

规则写不动的时候，模型是最后一根稻草；但它也会一本正经地胡分类。

```python
def classify(text: str) -> str:
    prompt = f"把下面这句话归到 [技术/生活/其他] 之一：\n{text}"
    return call_model(prompt, temperature=0)
```

## 三个坑

1. 输出不受约束 —— 让它「只输出一个词」，它还是会加解释。
2. 标签边界不清 —— 你自己都说不清的两个类，模型也分不清。
3. 没有回归集 —— 改一次 prompt 就得全部重测。

> 结论：先攒 50 条标注样本，再谈 prompt 优化。
